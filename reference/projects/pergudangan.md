
# Project: Pergudangan

## Basic Information

- Project name: Product Inventory
- Project type: Web Application
- Project category: Inventory / Warehouse Management
- Project status: Academic Project

## Project Overview

### English
A warehouse management system with two user roles, admin and owner, designed to address issues related to recording and tracking incoming and outgoing goods.

### Indonesian
Sistem pergudangan yang dengan dua user yaitu admin dan pemilik yang menyelesaikan permasalahan pencatatan alur masuk dan keluar barang.

## Problem
Pemilik terkadang kehilangan catatan tentang barang apa saja yang telah keluar dan masuk.

## Goal

Provide a web-based platform for A warehouse to track incoming and outgoing goods.

## Verified Features

List only features that have actually been implemented.

- User authentication and role-based access for admin and owner.
- Product management for admin.
- Dashboard with a transaction graphics.

## Technology Stack

- Frontend: HTML, CSS, JavaScript, and Tailwind CSS
- Database: MySQL
